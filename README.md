# Local moment bounds for positivity of the theta method on reversible networks

Companion code and numerical results for the manuscript with this title.

## Files

- `network_experiments.py`: generates the 18 deterministic network benchmarks, evaluates the step bounds, computes the positivity thresholds, and checks resolvent diagonals using sparse direct solves.
- `plot_network_results.py`: generates the comparison figure from `network_results.json`.
- `network_results.json`: recorded results for all 18 cases, including the problem definitions, numerical environment, computed thresholds and validation records.

All network inputs are generated by the code. No external dataset is required.

## Requirements

The benchmark results were generated with Python 3.9.6, NumPy 1.26.4 and SciPy 1.13.1. The figure was generated with Matplotlib 3.7.2.

For that dependency configuration, using Python 3.9:

```sh
python3 -m pip install numpy==1.26.4 scipy==1.13.1 matplotlib==3.7.2
```

## Reproduce the results

Keep the four repository files together and run these commands from their directory:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 python3 network_experiments.py
python3 plot_network_results.py
```

The first command regenerates `network_results.json`, `network_results.csv` and `network_table_all.tex`. It also performs the direct-solve validation checks. The second generates `figures/network_thresholds.pdf` and `figures/network_thresholds.png`.

To generate the figure from the deposited results without rerunning the benchmarks, run only the second command.

The benchmark program regenerates the recorded JSON file when run with the command above. Numerical results can differ slightly across numerical-library and platform configurations. The recorded timings are single-run diagnostics and are not performance comparisons.
